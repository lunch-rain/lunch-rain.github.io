# RainLove 的博客

基于 [Firefly](https://github.com/CuteLeaf/Firefly) 的个人博客，配有仅在本地运行的内容管理器。

## 启动

Windows 直接双击 `启动管理器.bat`。首次使用 Vercel 时再双击 `配置Vercel.bat`。

```powershell
pnpm install --frozen-lockfile
pnpm manager
```

管理器：<http://localhost:4174>  
博客预览：<http://localhost:4321>

在管理器里编辑文章、个人资料、主题文件和站点设置；确认预览后，打开「同步发布」上传 GitHub 或 Vercel。首次发布配置见 [LOCAL-MANAGER.md](LOCAL-MANAGER.md)。
