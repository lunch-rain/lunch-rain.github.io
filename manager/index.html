04 · Vercel 直发

直接发布生产环境

首次双击 配置Vercel.bat 登录并关联项目。

首次发布前

  1. GitHub 仓库 Settings → Pages → Build and deployment 选择 Deploy from a branch，分支选 gh-pages，目录选 /(root)。
  2. 如需源码推送后自动部署 Vercel，请在 Vercel 中连接上方源码仓库和分支；直接发布按钮仍可独立使用。
  3. 更改站点网址后，请在「站点设置」里填写实际对外域名。
