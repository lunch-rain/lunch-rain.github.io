首次请双击项目里的 配置Vercel.bat，登录并关联项目。

首次发布前

  1. GitHub：创建空仓库 lunch-rain.github.io，并确保本机 Git 可推送。若使用 GitHub Pages，在仓库设置中选择 GitHub Actions。
  2. Vercel：双击 配置Vercel.bat 登录并关联项目；之后即可使用上方按钮直接部署。
  3. 如果同时在 Vercel 连接 GitHub 仓库，推送 GitHub 也会触发 Vercel 自动部署。站点网址请在「站点设置」中改成实际对外域名。
