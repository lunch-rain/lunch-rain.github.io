这篇文章写给以后想更新博客、却忘了操作步骤的自己。记住一句话就够了：**先在本地保存并预览，再把改动发布到线上。** “保存到本地”不会自动更新网站。

## 想做什么，去哪里？

| 我想…… | 在管理器中打开 |
| --- | --- |
| 写一篇完整的记录或教程 | **文章管理 → 新建文章** |
| 分享几句话或一张照片 | **动态发布 → 新建动态** |
| 整理文章配图、头像、壁纸 | **图片管理** |
| 创建博客相册 | **相册管理** |
| 修改博客名称、横幅、个人资料 | **站点设置** |
| 把改动带到网站上 | **同步发布** |

打开管理器的方法：双击博客项目文件夹里的 **`启动管理器.bat`**。管理器右上角的 **预览博客** 可以查看本地效果。如果预览打不开，先确认启动窗口没有报错，再重新打开管理器。

## 一篇文章怎样从想法变成网页

1. 在 **文章管理** 中写标题、摘要、正文，选好分类和标签。正文支持 Markdown：`## 小标题`、`- 列表项`、`[链接文字](网址)`。
2. 暂时不想公开就勾选 **草稿**。草稿可以保存和继续编辑，但不会作为正式文章出现在网站上。
3. 点击 **保存到本地**，再打开本地博客。读一遍正文，点开链接，并检查图片是否加载。
4. 确认无误后去 **同步发布**：先点 **编译并推静态页**，再点 **同步源码到 GitHub**。前者更新 GitHub Pages；后者让连接 `main` 分支的 Vercel 开始构建。

动态更简单：在 **动态发布** 写好内容、预览后点 **保存并发布**，管理器会完成保存和两步同步。

## 图片怎么放，才不会以后找不到

文章编辑页可以直接上传配图。如果想长期整理素材，去 **图片管理** 新建文件夹、上传图片，再复制站内路径插入文章。默认的“图片库”也会显示在博客[相册](/gallery/)中；想把旅行、日常等照片分开，就在 **相册管理** 新建相册并填写名称、描述、标签和封面。

**删除图片前，先看看文章、头像或壁纸是否还在使用它。** 文件删除后，引用它的地方会变成空白或破图。

## 发布前的一分钟检查

- 文章不是草稿；标题、摘要和日期都正确。
- 电脑和手机宽度下，正文能读、图片能看。
- 外部链接能打开，公开内容没有不想暴露的个人信息。
- 发布按钮都显示成功，再打开线上页面检查。

如果**本地正常、线上还是旧版**，先确认是否只点了“保存到本地”；再看静态页与源码是否都同步成功。Vercel 自动构建和页面缓存可能需要一点时间，稍后刷新再看。若首页已经出现新文章、文章链接却暂时打不开，可以先等部署完成再重试。

最后，写作时不必追求一次写完。只要记下 **发生了什么、自己怎样解决、下次可以怎样更快完成**，这篇记录就已经对未来的自己有用了。
